# nasimlat.github.io

Личная витрина: работы, исходники, ссылки. Живёт на https://nasimlat.github.io/

Один файл `index.html` — ни сборки, ни зависимостей, ни Jekyll (`.nojekyll`).
Правится и коммитится напрямую, GitHub Pages публикует ветку `master` из корня.

Шрифты — PT Sans Narrow / PT Serif / PT Mono, подключены с Google Fonts.
Если понадобится работать без внешних запросов, их можно положить рядом
и заменить `<link>` на локальный `@font-face`.

## Переезд на nasimlat.ru

Когда домен будет зарегистрирован:

1. Положить в корень файл `CNAME` с единственной строкой `nasimlat.ru`.
2. У регистратора добавить A-записи на `185.199.108.153`, `185.199.109.153`,
   `185.199.110.153`, `185.199.111.153` и `CNAME` для `www` → `nasimlat.github.io`.
3. В настройках репозитория (Pages) дождаться проверки домена и включить
   Enforce HTTPS.

Адрес `nasimlat.github.io` продолжит работать редиректом.
